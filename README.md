# Excel Data Cleaning & Analysis — Week 1

## 📌 Project Overview

This project is part of my Week 1 Excel & Data Cleaning practice.

The project focuses on cleaning, analyzing, and visualizing sales data using Microsoft Excel.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Conditional Formatting
- Excel Statistical Functions
- Excel Charts

## 📊 Tasks Completed

### 1. Data Cleaning
- Removed duplicate records
- Handled missing values
- Prepared the dataset for analysis

### 2. Region-wise Sales Analysis
Created a Pivot Table to analyze:
- Region-wise order count
- Region-wise total sales

### 3. Statistical Analysis
Calculated:
- Mean
- Median
- Mode

### 4. Top 10 Sales Analysis
Used Conditional Formatting to highlight the top 10 sales values.

### 5. Category-wise Revenue Analysis
Created:
- Category-wise revenue Pivot Table
- Category-wise revenue Bar Chart
